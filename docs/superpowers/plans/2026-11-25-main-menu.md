# 메인 메뉴 개편 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 시작 화면 뒤 메뉴 네 개(발음연습·원고관리·녹음관리·퍼펙트딕션)와 폴더 관리를 만들고 v0.4.0-dev로 배포한다.
**Spec:** `docs/superpowers/specs/2026-11-25-main-menu-design.md`

## Global Constraints
- DB 변경은 추가만(v5). 화면 문구 한국어. "발음 점수"·"발음 채점" 금지. 인터넷 금지.

## Review Focus
1. **폴더를 지우면** 안의 원고와 녹음이 남는다. → Task 1 테스트
2. **같은 이름·빈 이름 폴더**는 만들 수 없다. → Task 1 테스트
3. **복제한 원고의 메모·표시를 고쳐도 원본은 그대로.** → Task 1 테스트
4. **녹음이 하나도 없을 때 녹음관리**가 안내를 보여준다. → Task 4 테스트
5. **원고를 지우면 녹음관리에서도 그 녹음이 사라진다.** → Task 4 테스트

### Task 1: DB v5와 저장소
**Files:** `lib/data/database.dart`, `lib/data/models.dart`(Script.folderId, Folder), `lib/data/folder_repository.dart`, `lib/data/script_repository.dart`, `lib/data/session_repository.dart` · Test `test/data/folder_repository_test.dart`
**Produces:** `currentSchemaVersion = 5`; `class Folder { int? id; String name; DateTime createdAt; }`; `FolderRepository`: `all()`, `add(String name) → int`(공백·중복이면 ArgumentError), `rename(int id, String name)`(같은 규칙), `delete(int id)`(원고는 folder_id NULL); `ScriptRepository`: `add`가 folderId 저장, `all()`이 folderId 포함, `moveToFolder(int scriptId, int? folderId)`, `duplicate(Script s) → int`(제목 "(복사본)", 표시·메모 복사); `SessionRepository.all()`(최신순).
- [ ] 테스트 → FAIL → 구현 → PASS → 커밋
