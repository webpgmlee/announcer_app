# 노래방식 원고 진행 설계 (짧은 설계)

작성일: 2026-11-25 · 상태: 사용자 승인 (대화에서 "Yes, go ahead")
바꾸는 문서: `2026-11-25-my-diction-redesign-design.md`의 4장(실시간 인식으로 위치 따라가기)

## 무엇을, 왜

녹음 화면이 목소리를 따라가는 대신, 노래방 기계처럼 정해진 속도로 지금 문장을 한 글자씩 채워 가고 문장이 끝나면 다음 문장으로 넘어간다. 사용자가 일정한 뉴스 속도에 맞춰 읽는 연습을 하기 위해서다.

## 정한 것

- **문장 단위:** `//`(숨) 표시까지가 한 문장. 지금 문장은 크게 가운데, 앞 문장은 흐리게 위, 다음 문장은 아래.
- **채우기:** 지금 문장의 글자가 속도에 맞춰 흐린 색에서 진한 색으로 채워진다. 어절마다 걸리는 시간 = 어절의 읽는 소리 음절 수 ÷ 속도.
- **쉬는 시간:** `/` 뒤 0.3초, `//` 뒤 0.6초.
- **기본 속도:** 1분당 350음절 (방송 뉴스 낭독 보통 330~370). 조절 범위 200~500, 한 번에 10. 녹음 전에만 바꿀 수 있고, 바꾼 값은 앱을 다시 켜도 남는다 (DB v4 `settings` 테이블, 추가만).
- **시작과 끝:** 녹음 버튼을 누르면 녹음은 바로 시작하고, 3-2-1 카운트다운 뒤 진행이 시작된다. 마지막 문장이 끝나고 1.5초 뒤 녹음이 자동으로 멈춘다. 정지 버튼으로 언제든 멈출 수 있다.
- **시계:** 진행 시간은 녹음된 소리의 길이(샘플 수)로 잰다. 녹음과 진행이 어긋나지 않는다.
- **빠지는 것:** 실시간 인식(`LiveTranscriber`), 위치 추정 안내, 목소리로 잰 속도 표시(느림/적당/빠름). 녹음 뒤 원고 비교는 녹음 파일 인식으로 한다 (v1과 같음).
- **남는 것:** 끊어 읽기 표시 편집, 메모, 자주 틀림, 크기 표시, 파형, 대본 %·남은 시간(진행 시간표로 정확히 계산), 진행 막대, 결과 화면.

## 방식 검토

| 방식 | 판단 |
|---|---|
| **정해진 속도로만 진행 (선택)** | 가볍고 모든 폰에서 같은 속도. 노래방 요청 그대로. |
| 목소리 따라가기를 남기고 노래방을 선택 기능으로 | 두 방식을 함께 유지해야 해 복잡. |
| 정해진 속도로 진행하며 실시간 인식도 계속 | 진행에 쓰지 않는데 배터리만 씀. |

## 빌더에게 맡기는 것

채우기 색, 카운트다운 모양, 속도 조절 버튼 모양, 화면 갱신 주기.
