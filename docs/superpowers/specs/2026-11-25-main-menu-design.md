# 메인 메뉴 개편 설계 (짧은 설계)

작성일: 2026-11-25 · 상태: 사용자 승인 ("네, 진행해 주세요")

## 무엇을, 왜

아래 탭(대본·녹음·기록)을 없애고, 시작 화면 뒤에 메뉴 네 개를 둔다. 사용자가 원하는 앱 구성(연습, 원고 관리, 녹음 관리, 앞으로의 퍼펙트딕션)을 첫 화면에서 바로 보이게 하기 위해서다.

## 정한 것 (사용자 결정)

1. **발음연습:** 원고 선택 → 녹음 시작(지금의 노래방식 녹음 화면).
2. **원고관리:** 조회, 추가, 복제, 삭제, 폴더 관리(추가, 이름 수정, 삭제). **원고 수정은 하지 않는다.**
3. **녹음관리:** 사용자가 연습한 녹음 기록 조회, 삭제.
4. **퍼펙트딕션:** 이름만 두고 기능은 나중에.

## 설계자 판단

- 메뉴는 2×2 카드. 각 메뉴는 화면을 새로 열고 뒤로 가기로 돌아온다.
- 발음연습: 위쪽 폴더 칩(전체 + 폴더들)으로 원고를 거른다.
- 원고 조회: 본문 전체, 음절 수, 녹음 횟수.
- 원고 추가: 붙여넣기 화면에서 폴더를 고를 수 있다.
- 복제: 제목 뒤에 "(복사본)", 본문·폴더·끊어 읽기 표시·메모를 복사, 녹음은 복사하지 않는다.
- 폴더 이동: 폴더를 쓰려면 필요해서 원고마다 넣는다.
- 폴더 삭제: 안의 원고는 지우지 않고 "폴더 없음"으로 옮긴다. 폴더 이름은 비울 수 없고 겹칠 수 없다.
- 녹음관리: 모든 원고의 녹음을 최신순으로(원고 제목, 날짜, 걸린 시간, 1분당 음절). 누르면 결과 화면, 밀어서 확인 후 삭제(녹음 파일도 삭제).
- 퍼펙트딕션: "준비 중" 카드, 누르면 "곧 만나요" 안내. 빌드 설정 `SHOW_PERFECT_DICTION=false`로 숨길 수 있게 해 둔다(스토어 심사에서 미완성 기능으로 보이지 않게). "점수" 같은 과장 문구는 쓰지 않는다.
- DB v5(추가만): `folders(id, name UNIQUE, created_at)`, `scripts.folder_id`. 기존 원고는 폴더 없음.

## 방식

지금 녹음·저장·노래방 진행을 그대로 두고 화면 구성과 폴더만 새로 만든다. 처음부터 다시 짜는 방법은 검증된 부분을 버리게 되어 고르지 않았다.

## 하지 않는 것

원고 본문 수정, 퍼펙트딕션 기능, 폴더 안의 폴더.
