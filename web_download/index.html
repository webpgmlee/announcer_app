아나운서 연습

원고를 소리 내어 읽으면 시간과 말 빠르기를 재고, 억양을 선으로 보여주고, 원고와 다르게 들린 단어를 표시해 주는 앱입니다.

시험판 spike-1 174MB 안드로이드 7 이상
지금 받는 파일은 정식 앱이 아니라 음성 인식 엔진 시험용 앱입니다. 들어 있는 샘플 낭독을 폰에서 글자로 바꿔 보고, 걸린 시간과 원고와의 일치율을 보여줍니다.

설치 방법

  1. 위 버튼을 눌러 APK를 받습니다. 용량이 크니 와이파이에서 받는 것을 권합니다.
  2. 받은 파일을 엽니다. "출처를 알 수 없는 앱" 안내가 나오면, 사용 중인 브라우저의 설치 권한을 허용합니다.
  3. 설치가 끝나면 앱을 열고 base 버튼을 누릅니다.

개인정보

  • 음성 인식은 폰 안에서만 돌아갑니다. 인터넷 연결이 필요 없습니다.
  • 녹음과 결과는 폰 밖으로 보내지 않습니다.
